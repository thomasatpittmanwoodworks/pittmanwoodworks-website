# pittmanwoodworks.com

Website for Pittman Woodworks, commercial casework and countertops in North Richland Hills, Texas.

## Pages
- `index.html` — Home (industries, construction, process, projects, bidding, FAQ, contact)
- `about.html` — About and team
- `careers.html` — Careers and job applications

## Hosting
Hosted on Netlify. Every change saved to the `main` branch publishes automatically.
`netlify.toml` holds redirects from the old Wix page addresses.

## Editing
- Team members: edit the `TEAM` list near the bottom of `about.html`.
- Job listings: edit the role sections in `careers.html`.
- Client names/logos: edit the `clients` list near the bottom of `index.html`.
